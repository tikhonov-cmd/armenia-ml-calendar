# Календарь ML-траекторий в Армении

[Открыть календарь](https://tikhonov-cmd.github.io/armenia-ml-calendar/)

Годовая шкала и справочник открытых каналов поиска кандидатов в ML и смежных областях. В охват входят профильные олимпиады, вузы, школы, конкурсы, исследовательские группы, стажировки и сообщества. Это срез доступных открытых источников на 10 ноября 2026 года. Расписание на 2027 год можно дополнять по мере появления объявлений.

## Даты и сравнение

- На шкале видны этапы выбранного календарного года. Можно отфильтровать каналы по типу, аудитории, географии и поисковому запросу, а этапы по статусу дат.
- Сплошная отметка означает опубликованные даты, штриховая — ориентир по месяцам, точечная — предварительные даты с оговоркой организатора или анонс без проверенного подтверждения. Заявки и дни мероприятий отмечены как отдельные этапы. Нажатие на отметку открывает её описание и источник.
- Пересечение двух каналов считается по календарным дням, включая границы интервалов. Оно может быть ориентировочным и само по себе не показывает, что участникам приходится выбирать между событиями.
- Каналы без проверенных дат представлены в справочнике. Режим ближайших событий использует календарное время Еревана.

## Охват и значимость

- Каждое число снабжено периодом, единицей и источником. Сравнивать напрямую можно числа с сопоставимыми этапами, аудиториями и единицами. Сумма по каналам не равна числу уникальных людей.
- Редакционная шкала 0–3 оценивает описанный результат. 0 — точка входа, 1 — участие или зачисление, 2 — проверяемая работа, 3 — значимый конкурсный результат. Балл не измеряет вероятность поступления. Опубликованные правила вузов и условия льгот приведены отдельно.
- Имена участников и материалы интервью в набор данных не входят.

## Обновление

Добавьте или измените записи в `data.js`. Даты хранятся в формате YYYY-MM-DD. Укажите статус даты, вид этапа и ссылку на документ или объявление. Для числа укажите единицу, период и источник. Если организатор публикует только месяц, используйте границы месяца для построения шкалы со статусом `approximate`.

Страница работает как статический сайт без сборки. Для просмотра локальной версии откройте `index.html` в браузере.
